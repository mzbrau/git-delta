# Welcome to GIT DELTA

GIT DELTA is a fast, cross-platform Git client built for **code review**.

It helps you inspect local changes and pull requests quickly — with a large diff viewer, clear navigation, and optional AI assistance that supports your judgment instead of replacing it.

## Who this is for

- Developers reviewing their own work before they push
- Senior engineers reviewing teammates’ (and AI-generated) changes
- Teams on Windows or macOS who need a responsive desktop client in large or “slow disk” environments

## What you can do

| Area | Examples |
| --- | --- |
| Local Git | Stage, commit, push/pull, history, stash, rebase |
| Diffs | Side-by-side or unified, hunk and line staging, syntax highlighting |
| Pull requests | Inbox, comments, viewed files, submit reviews |
| AI assist | Briefings, annotations, and chat — advisory only |
| Settings | Theme, accounts, diff defaults, AI options, diagnostics |

## Platforms

- **Supported:** Windows and macOS
- **Not supported:** Linux

You need **Git 2.30+** on your PATH. GIT DELTA drives the `git` CLI; it does not bundle Git.
